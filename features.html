Core Module Features

Designed with cutting-edge web technologies to create an immersive, interactive, and autonomous learning experience.

🔊

Native Pronunciation Audio

Utilizes browser text-to-speech engine (`SpeechSynthesis`) to play standard native audio models for tour guiding expressions clearly.

🎙️

Speech Recognition Assessment

Students can record their voice directly in the browser (`SpeechRecognition`) to receive instant evaluation and build speaking confidence.

📱

Cross-Device Responsiveness

Optimized layout using Tailwind CSS ensuring smooth navigation, clean reading views, and touch-friendly controls on smartphones and laptops.

🛡️

Safety Procedures Simulation

Structured card-based learning modules focusing on emergency handling, safety briefings, and precise directional guidance.

⚡

Zero-Installation Web Access

Hosted permanently on GitHub Pages, requiring no app store downloads—just open the browser link to start learning immediately.

📖

Pedagogical Structure

Built following academic standards and instructional design frameworks to ensure optimal competency achievement for vocational students.
